Agente de IA Conversacional para Atención al Cliente

Un proyecto-práctica enfocado en el desarrollo de un agente de inteligencia artificial autónomo y contextual para automatizar la atención al cliente, la gestión comercial y el registro de prospectos.
Creado con python 3
Modelo de lenguaje: Llama 3

Que hace?
Responde preguntas de clientes en lenguaje natural
Consulta precios de programas automáticamente
Verifica disponibilidad de cupos en tiempo real
Registra nuevos contactos , evitando duplicados
Recuerda el contexto de la conversación completa, no responda preguntas aisladas

El archivo Knowledge_base.py actua como una simulacion de la base de datos.
